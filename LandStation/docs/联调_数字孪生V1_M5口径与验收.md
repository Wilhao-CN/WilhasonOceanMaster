## 4. 🔴 R9 红线与开噪副作用（排查手册必读条目）

**红线**：

- 孪生**绝不发 `NaN` / `lat=lon=0`**；「无效」一律表现为**保持上一帧值**。
- 地面站侧**无兜底**：收到 `0` 会被当真值算进 A+B 中点 ⇒ **船位瞬移**。
- ⇒ **排查顺序**：地图上船位突然跳到异常位置/几内亚湾方向 → **先查是否收到 `lat=lon=0` 或异常帧**，再查链路。

**开噪（σ>0）后的 4 个已知副作用**（属正常现象，非故障）：

1. 打卡判据 `dist<2.0 m` 会**提前/漏打卡**；
2. 图标**抖动**；
3. `smooth_speed` 位置差分产生**速度尖峰**（不进控制环，但污染日志）；
4. 50 Hz 注入 vs 5 Hz 消费 = **等效抽样**，影响比想象小。
