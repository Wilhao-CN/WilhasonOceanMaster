# 完整动力学参数参考 / Complete Hydrodynamic Parameters

> **与数字孪生一一对应**：本文件是数字孪生「参数设置」窗口（按 `F8` 展开）与本地存档文件 `dt_params.json` 中**每一个参数**的权威清单。
>
> 包含：键名、中文标签、单位、参数窗口分组、**当前生效的默认值**、可调范围及物理含义。
> 注意：**小船（即子船，`0x02`）**

---

## 1. 参数系统总览

| 项 | 值 |
|---|---|
| 窗口入口 | 数字孪生内按 **`F8`**（或右上角 `◀ HUD`）展开控制面板 → **「参数设置」** |
| 窗口操作 | 底部 **恢复默认 / 保存 / 导出 / 导入** |
| 参数总数 | **59 个非浮力键** + 浮力 9 键 × 2 载体（18 条）= 窗口共 **77 条参数** |
| 修改生效 | **即时生效**（无需重启）；标「需重新入水才生效」的项例外 |
| 存档文件 | `<exe 同目录>\dt_params.json`（+ `.bak`）；若该目录不可写，回退至 `…\LocalLow\SCUT_NOF\USV_Sim2Real_Simulation_Platform\` |
| 导出快照 | `<参数目录>\ParamsExport\`；可改名 / 删除（限定在该目录内，防路径穿越） |

### 1.1 参数窗口分组

窗口内实际呈现的分组如下：

| 分组 | 内容 | 备注 |
|---|---|---|
| **力映射 · PWM ↔ 力** | 曲线系数可改；**`pwmMid` 与 `exponent` 只读**；右侧有曲线预览 | 顶部常驻红字警告（见 §2） |
| **载体动力学 · 小船 / 船坞** | 质量、转动惯量、阻尼系数、推力与扭矩限幅 | 即时生效 |
| **传感器 · GPS 噪声** | `σ`（默认关闭）、零偏、随机种子 | 见 §7.1 副作用与红线 |
| **相机 · 视场角** | 三个屏幕相机 FOV | 推流画面同步跟随 |
| **环境 · 波浪 / 水材质 / 浮力 / 光照** | 波浪幅度、频谱、水色、浮力组（按对象）、太阳方位/强度、雾 | 修改资产类参数会自动创建运行时副本，不动原始资产 |
| **GNSS · 锚点** | `lat0/lon0` + 地图四角 + **【应用锚点】复合按钮** | 一次点击内完成“改锚点 → 重算四角 → 刷新” |
| **通信端口 / IP** | **只读**回显 | 修改端口请重新构建；修改 IP 请改 `gcs_target_ip.txt` |

### 1.2 存盘三规则（参数契约）

1. **只写非默认项**：`Save()` 跳过出厂默认值，`dt_params.json` **只包含你修改过的项**。刚装完没改过参数时，**不会**生成该文件（正常现象）。
2. **载入先回默认**：`Load()` / 导入时，**先把全部参数恢复出厂值**，再套用文件里的项。文件里缺失的项 = 使用出厂值。
3. **容差吸附**：与出厂值相对误差 **< 1e-6** 的项视为“默认”（避免“看着是默认其实偏了”）。

## 2. 力映射 · PWM ↔ 力（`curve.*`）

> **唯一与真船/地面站强一致的参数组**：默认值 = 与真船一致的权威实测值。
> ⚠️ 窗口顶部常驻红字警告：**「修改力映射后，孪生将不再代表真船 —— 仅适合适配你自己的推进器。」**

**计算公式**：
```
pwm = A·f² + B·f + pwmMid          （f > 0 用 posA/posB；f < 0 用 negA/negB）
pwmMid 只读 = 1500，须与地面站一致
```

| 参数键 | 中文标签 | 单位 | 默认值 | 范围 | 含义 |
|---|---|---|---:|---|---|
| `curve.posA` | 正向 A | — | **-0.65914714** | [-10, 0] | 正向二次项 |
| `curve.posB` | 正向 B | — | **37.584549** | [0, 100] | 正向一次项 |
| `curve.negA` | 反向 A | — | **-0.73450941** | [-10, 0] | 反向二次项 |
| `curve.negB` | 反向 B | — | **14.967582** | [0, 100] | 反向一次项 |
| `curve.maxForcePos` | 正向力上限 | N | **9.5974** | [0.1, 50] | `f = +maxForcePos` ⇒ 满杆正转 |
| `curve.maxForceNeg` | 反向力上限 | N | **9.2045** | [0.1, 50] | `f = -maxForceNeg` ⇒ 满杆反转 |
| `curve.pwmMid` | PWM 中位 | 计数 | **1500**（只读） | [900, 2100] | 中位 PWM，须与地面站一致 |
| `curve.exponent` | 摇杆曲线指数 | — | 组件现值 | [1, 3] | 仅作用于虚拟摇杆，不影响地面站 |

**与地面站逐字一致（必须相同）**——见地面站 `core/protocol.py` 的 `force_to_pwm()`：
- 正向：`-0.65914714·f² + 37.584549·f + 1500`
- 反向：`-0.73450941·f² + 14.967582·f + 1500`
- 限幅 `1000–2000`

> 改这 6 个系数后：孪生的 PWM↔力 关系与真船分叉，"孪生 = 真船"**只在默认值下成立**。
> 回到一致：点击窗口「**恢复默认**」，或导入一份出厂 preset。

## 3. 载体动力学 · 小船（`usv.*`）

> 分组 `载体动力学 · 小船`。若场景中找不到该组件，窗口会报错提示不可调。
> 注：u/v/r 均基于**船体坐标系**（Body-fixed frame，随船运动），非大地坐标系。

| 参数键 | 中文标签 | 单位 | 默认值 | 范围 | 含义 |
|---|---|---|---:|---|---|
| `usv.M` | 质量 M | kg | **23.8** | [1, 500] | 船体质量 → `Rigidbody.mass` |
| `usv.I` | 转动惯量 I | kg·m² | **1.76** | [0.01, 100] | 艏摇惯量 → `inertiaTensor` |
| `usv.Xu` | 纵向阻尼 Xu | — | **0.7225** | [0, 200] | 纵向线性阻尼，力 `= -Xu·u` |
| `usv.Yv` | 横向阻尼 Yv | — | **0.8897** | [0, 200] | 横向线性阻尼，力 `= -Yv·v` |
| `usv.Nr` | 艏摇阻尼 Nr | — | **1.9** | [0, 200] | 艏摇线性阻尼，力矩 `= -Nr·r` |
| `usv.MIN_Tu` | 推力下限 | N | **-10** | [-100, 0] | 总推力钳位下限（最大倒车推力） |
| `usv.MAX_Tu` | 推力上限 | N | **30** | [0, 100] | 总推力钳位上限 |
| `usv.MIN_Tr` | 力矩下限 | N·m | **-15** | [-50, 0] | 艏摇力矩钳位下限 |
| `usv.MAX_Tr` | 力矩上限 | N·m | **15** | [0, 50] | 艏摇力矩钳位上限 |

- `MIN/MAX_Tu`、`MIN/MAX_Tr` 是**总推力/总力矩的最终钳位**：任何分配算法的结果都被夹进该区间。
- 小船推进器分配另受 **ratio 钳位**约束（见 §5.2）：主推 `-0.50..+0.75`、转向 `±0.25`。

### 5.2 推进器布置与真船满杆表

**推进器布置**：`T1_RearLeft` / `T2_FrontLeft_Minus45` / `T3_FrontRight_Plus45` / `T4_RearRight`。

**真船权威满杆 PWM（默认系数下）**：

| 载体 | 满杆前进（ch1/2/3/4） | 满杆后退（ch1/2/3/4） | 满舵右（ch1/2/3/4） | 满舵左（ch1/2/3/4） |
|---|---|---|---|---|
| 小船 `0x02` | `1736 / 1500 / 1500 / 1736` | `1415 / 1500 / 1500 / 1415` | `1500 / 1586 / 1461 / 1500` | `1500 / 1461 / 1586 / 1500` |
| 船坞 `0x01` | `1799 / 1500 / 1500 / 1799` | `1300 / 1500 / 1500 / 1300` | `1500 / 1700 / 1300 / 1500` | `1500 / 1300 / 1700 / 1500` |

> 注：满杆后退为主推通道（ch1 / ch4）反向、转向通道（ch2 / ch3）保持中位 1500。

- 小船主推 ratio 钳位 **−0.50..+0.75**、转向 **±0.25**。
- 船坞主推 **±1.25**、转向 **±0.50**（**手动路径不钳**，由 1300–1700 窗口钳位；**PID 巡线钳 ±0.50** → 1665/1415）。
- 手动摇杆与 PID 巡线是**两条不同路径**，船坞转向 1700/1300 与 1665/1415 都是对的，取决于走哪条。

## 7. 传感器与相机（`gps.*` / `cam.*`）

### 7.1 GPS 噪声（分组 `传感器 · GPS 噪声`）

| 参数键 | 中文标签 | 单位 | 默认值 | 范围 | 说明 |
|---|---|---|---:|---|---|
| `gps.sigma` | 位置噪声 σ | m | **0（关闭）** | [0, 5] | 截断高斯；注入点在遥测发送前（地面站无感） |
| `gps.bias` | 位置零偏（北+东） | m | **0** | [-5, 5] | 北 / 东各偏该值 |
| `gps.seed` | 随机种子 | — | **固定（可复现）** | [0, 999999] | 同种子 = 同序列 |

> 开噪后的 **4 个已知副作用**：① 打卡判据 `dist < 2.0 m` 提前或漏打卡；② 图标抖动；③ `smooth_speed` 位置差分产生速度尖峰；④ 50 Hz 注入 vs 5 Hz 消费导致等效抽样。
>
> 🔴 **红线（绝不触碰）**：**绝不发 `NaN` / `lat=lon=0`** —— 地面站无兜底，`0` 会被当真值算进 A+B 中点 ⇒ **船位瞬移**。"无效"一律表示为**保持上一帧值**。

### 7.2 相机 FOV（分组 `相机 · 视场角`）

| 参数键 | 中文标签 | 单位 | 范围 | 相机对象 |
|---|---|---|---|---|
| `cam.boat` | 小船视角 FOV | ° | [10, 120] | `Camera_main` |
| `cam.dock` | 船坞视角 FOV | ° | [10, 120] | `Dock` |
| `cam.global` | 全局视角 FOV | ° | [10, 120] | `Globalmap` |

> 注：正交投影相机的 FOV 无效，系统会自动跳过。
