## R1 · 改了力映射，孪生就不再代表真船

**「参数设置」窗口 → `力映射 · PWM ↔ 力` 分组**可改 6 个系数
（`posA` / `posB` / `negA` / `negB` / `maxForcePos` / `maxForceNeg`）：

```
pwm = A·f² + B·f + pwmMid      （pwmMid 只读 = 1500，须与地面站一致）
```

⚠ **窗口顶部常驻红字警告**：

> **修改力映射后，孪生将不再代表真船 —— 仅适合适配你自己的推进器。**

- **默认值 = 与真船一致的权威实测值**（见 §R2 的两组数），**不要为了"看着顺眼"随手改**
- 改过之后：孪生与真船的 PWM↔力 关系不再一致，"孪生 = 真船"的前提**只在默认值下成立**
- 想回到真船一致：用窗口的「**恢复默认**」，或导入一份出厂 preset
- 曲线顶点 / 力上限见窗口内的曲线预览（纵轴 = ±力上限），改 `maxForce*` 会同步缩放纵轴

## R2 · 船坞转向的两个值：**手动路径 vs 自动循迹路径**

| 路径 | 是否钳 `ratio` | 船坞转向（ch2/3）最终 PWM |
|---|---|---|
| **手动摇杆**（虚拟摇杆 / 键盘 / 方向盘 / 地面站手动） | ❌ 不钳 | **1700 / 1300** ← **V1 虚拟摇杆取这个** |
| **PID 巡线 / 自动**（走 `_allocate_thrust`） | ✅ 钳到 ±0.50 | **1665 / 1415** |

> **写清楚的原因**：将来有人拿 V1 的值去对**自动巡线**，会以为差错了。
> 两者都是对的，取决于走哪条路径。

**权威实测值全表**（默认系数下）：

| 载体 | 满杆前进 | 满杆后退 | 满舵右（ch1/2/3/4） | 满舵左 |
|---|---|---|---|---|
| 小船 `0x02` | `1736 / 1500 / 1500 / 1736` | `1415` | `1500 / 1586 / 1461 / 1500` | `1500 / 1461 / 1586 / 1500` |
| 船坞 `0x01` | `1799 / 1500 / 1500 / 1799` | `1300` | `1500 / 1700 / 1300 / 1500` | `1500 / 1300 / 1700 / 1500` |

- 小船主推 ratio 限幅 **−0.50..+0.75**、转向 **±0.25**（ratio 钳位先生效）
- 船坞主推 ratio 限幅 **±1.25**、转向 **±0.50**（手动路径不钳，由 1300–1700 窗口钳位）

## R3 · 图标位置口径（已知并接受的 ~0.5 m 差）

| 位置 | 含义 |
|---|---|
| **地面站图标** | = **天线 A** |
| **地面站算法使用的位置** | = **A + B 中点** |
| **孪生小地图图标** | = **A + B 中点** |

⇒ 地面站图标与算法位置、以及孪生图标之间**存在约 0.5 m 的系统偏差**。
**这是已知且双方接受的口径**（改动地面站图标属共用代码改动，V1 不做）。
另：船坞 GPS 天线的**虚拟布置方向**当前为前后（实船为左右），亦计入该偏差。

## R4 · 巡线可用：只要孪生处于「接收地面站模式」

- ✅ **孪生处于"接收地面站模式"时**：地面站的**巡线 / 打点结果**会通过控制帧驱动孪生
  —— 孪生只需收 **33 字节 PWM** 就能被驱动，**不需要**孪生自己有循迹算法
- ❌ **孪生处于本地模式**（屏蔽下行 / 本地接管 / 急停闩锁）时：**不会被地面站驱动**
  —— 这时"点了没反应"是**设计行为**，看孪生侧的模式指示即可

> ⚠ **不要写成"V1 不支持巡线"** —— 正确的说法是上面这条。

---

## R5 · 帧长与交互模型

- 数字孪生侧**忽略所有非 33 字节的帧**（扩展帧）—— **属正常行为，不是故障**
- 地面站 fire-and-forget，**不等回执**（孪生不回 ACK）
- 控制帧 **33 字节**、遥测帧 **65 字节**、遥测 **50 Hz**

## R6 · ⚠「一键启动数字孪生」会覆盖目标 IP

地面站的**「一键启动数字孪生」会把 `gcs_target_ip.txt` 覆盖为 `127.0.0.1`**
（`main_window.py:1876-1885`）。

⇒ 若孪生与地面站**不在同一台机器**：**先启动孪生、再点一键启动**，或点完之后**手动改回**目标 IP
并**重启孪生**（改 `gcs_target_ip.txt` 后重启即生效，无需重新构建）。

## R9 · 传感器噪声：默认关闭，开了有副作用

「参数设置」→ `传感器 · GPS 噪声`：

| 参数 | 默认 | 说明 |
|---|---|---|
| `σ`（位置噪声标准差） | **0 = 关闭** | 开噪声是**显式动作**，便于对照"干净 vs 带噪" |
| 零偏 | 0 | 北 / 东各偏这么多米 |
| 种子 | 固定 | **可复现**：同种子 = 同序列 |

- 实现为**截断高斯**（有界，不出离群值），注入点在 **Unity 侧遥测发送前** ⇒ 地面站无感

🔴 **红线（绝不触碰）**：**绝不发 `NaN` / `lat=lon=0`**。
地面站**无兜底**，`0` 会被当真值算进 A+B 中点 ⇒ **船位瞬移**。
"无效"一律表示为**保持上一帧值**；关闭噪声时**仍执行**该红线检查。

**开噪后的 4 个已知副作用（写在此处以免被当故障）**：

1. 打卡判据 `dist < 2.0 m` 会**提前或漏打卡**
2. 图标**抖动**
3. `smooth_speed` 位置差分会产生**速度尖峰**（不进控制环，但污染日志）
4. 50 Hz 注入 vs 5 Hz 消费 ⇒ **等效抽样**，实际影响比想象的小

## R10 · 力映射 preset 的格式与版本号（**待补版本字段**）

- **格式**：**没有单独的 preset 格式** —— 力映射系数与其余参数共用同一份参数库导出文件：
  ```json
  {
    "schema": "digitaltwin/params/v1",
    "values": [ { "key": "...", "value": "..." }, ... ]
  }
  ```
- **文件与目录**：
  - 参数存档：`<孪生 EXE 同目录>\dt_params.json`（该目录不可写时回退
    `%USERPROFILE%\AppData\LocalLow\<companyName>\<productName>\`）
  - 导出：`<参数目录>\ParamsExport\`（导入走"目录扫描 + 列表选择"，支持改名 / 删除）
  - 生成 `.bak` 备份
- **schema 版本号**：`digitaltwin/params/v1` —— 导入时**校验 schema**，
  **不符 ⇒ 拒绝且不改动任何当前值**
- ⚠ **待补**：计划 §4.1 约束 2 要求 preset 带**独立的版本号字段**（为 V2 方案 B 铺路）。
  当前实现**只有 `schema` 字符串，没有额外的 preset 版本字段** ⇒ **列为待补项**，不假装已有。

## 附：「只存非默认项 + 载入先回默认」（参数契约，纪律 ④）

这是 V1 的参数存盘规则，**与地面站无直接关系**，但会影响"改了什么、文件里能看到什么"：

1. **只写非默认项**：`Save()` **跳过出厂默认值**，`dt_params.json` **只含你改过的项**
   （⇒ 刚装完没改过参数时，**不会**生成这个文件，属正常）
2. **载入先回默认**：`Load()` / 导入时**先把全部参数回出厂值**，再套用文件里的项
   （⇒ 文件里"缺项"= 该项用出厂值，不会被上一次的遗留值污染）
3. **容差吸附**：与出厂值相对误差 < 1e-6 的项视为"默认"，避免"看着是默认其实偏了"

> 力映射系数以 **double** 存储与进 JSON（`G17` 字符串往返），**不经 float 往返**
> —— 否则 `1799.99985` 这类临界值会被推过 1.0，满杆 PWM 从 `1799` 变 `1800`。
