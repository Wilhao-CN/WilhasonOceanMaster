## 这是什么

这是一个用 **Unity** 实现的**无人船（USV）数字孪生仿真环境**，在虚拟场景中
1:1 镜像真船的物理行为、传感器遥测与地面站通信协议。

它同时是三样东西：

- **物理仿真器** —— 双体无人船与浮船坞的运动、浮力、波浪、水动力阻尼；
- **协议从站** —— 完整实现真地面站的控制帧下行与遥测帧上行协议（逐字节对齐）；
- **可视化终端** —— 三路实时视频、遥测面板、小地图与定位打点系统。

主要用于**演示、控制算法联调与教学**，可与配套的地面站软件或自研算法对接。

## 快速开始

1. 解压整个文件夹到任意路径（**路径建议不含中文或空格**）
2. 确认 `gcs_target_ip.txt` 里的目标 IP：
   - 与地面站**同一台电脑**运行 → 保持 `127.0.0.1`
   - 地面站在**另一台电脑** → 填地面站的实际 IP
3. 双击 `USV_Sim2Real_Simulation_Platform.exe` 启动
4. 按 **`F8`** 展开控制面板

> 修改 `gcs_target_ip.txt` 后**直接重启程序即可生效，无需重新构建**。

## 默认网络参数

### 视频（Unity 作为 TCP 服务端）

| 端口 | 画面 |
|---:|---|
| 5001 | 船坞视角 |
| 5002 | 全局俯视（小地图） |
| 5003 | 无人船视角 |

### 数据（UDP）

| 载体 | 控制（地面站 → 孪生） | 遥测（孪生 → 地面站） |
|---|---:|---:|
| 无人船（ID `0x02`） | **8888** | **8889** |
| 浮船坞（ID `0x01`） | **8081** | **8080** |

- 控制帧 **33 字节**，遥测帧 **65 字节**，遥测频率 **50 Hz**
- 程序**忽略所有非 33 字节的扩展帧**（属正常行为，非故障）

## 操作说明

| 操作 | 按键 |
|---|---|
| 展开 / 收起控制面板 | **`F8`** 或右上角 `◀ HUD` |
| **一键重置**（两船回到初始位置） | **`F5`** |
| 定位系统窗口全屏 | **`F6`** |
| 航向控制 | `W` 前进 / `S` 后退 / `A` 左转 / `D` 右转 |
| 切换视角 | 面板内按钮（无人船 / 船坞 / 全局） |
| 调节波浪 | 面板内"波浪调节"滑条 |

### 定位系统（V0.5 新增）

- **双击屏幕左下角的小地图**，或点面板里的 **「定位系统」** 按钮打开
- 窗口左侧工具列：
  - **浏览** —— 拖拽平移、滚轮缩放（每格 ×1.25）
  - **打点** —— 地图上左键落点、右键退点
  - **清除打点** —— 清空当前地图上的全部标记
- 窗口可拖动、缩放、关闭，**位置与大小会自动记忆**
- 地图上显示两船实时位置：
  - 🔵 蓝 = 无人船天线 A　🟦 青 = 船坞天线 A
  - 🩷 粉 / 🟡 金 = 天线 B
  - 🟢 绿 = **A+B 中点**（算法使用的参考位置）
  - 🟠 橙 = 你打的点

## 与地面站对接

本程序与配套地面站软件通过上述端口通信，协议**逐字节对齐真船**：

- 控制帧：`0xAA` 起始、`0x55` 结尾、和校验，4 路 PWM（1000–2000，中位 1500）
- 遥测帧：含 IMU、双天线 GPS、PWM 回传、温度、时间戳
- **多控制源仲裁**：本地手动 ＞ 地面站 UDP ＞ Python 算法接口（0.5 秒超时自动切换）

如需接入自研算法，可参考目录中的 `GROUND_STATION_INTERFACE.md`。

## 已知限制

- **打点数据只保存在内存**，退出程序后不会保留（与最新版行为一致）
- 船坞 GPS 天线的**虚拟布置方向与实船不一致**（当前为前后，实为左右），位置显示存在约 0.5 m 系统偏差 —— 已知问题，后续版本修正
- 启动时 Console 若提示 `Crest Validation: Foam is not enabled...`，属已知的渲染配置警告，**不影响功能**
- 定位系统的界面样式**尚未与最新版对齐**，后续版本统一
- 程序**不使用 NDI 推流**（三路视频走 TCP），也**不使用 OPC UA**

## 构建方式

从 Unity 工程重新构建：

```
Unity 菜单：Tools > Ground Station > Build Windows x64
```

或命令行批处理：

```
-batchmode -quit -projectPath <工程路径> ^
  -executeMethod GroundStationBuild.BuildWindows64 ^
  -gcsBuildPath <输出目录>\USV_Sim2Real_Simulation_Platform.exe
```

构建脚本会自动复制 `gcs_target_ip.txt` 与 `GROUND_STATION_INTERFACE.md` 到输出目录。
